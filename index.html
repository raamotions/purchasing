Daftar Pengajuan

Pengajuan hari ini tampil di atas, dikelompokkan per tahap dan asal barang (klik grupnya untuk melihat barang; tombol Download ada di tiap grup). Setelah pukul 00.00 WIB, pengajuan hari itu otomatis masuk ke Riwayat dan dikelompokkan per tahun & bulan (tertutup, klik untuk membuka). Filter tanggal & jam yang dikosongkan berarti semua tanggal, termasuk untuk export. Data penerimaan tetap tersimpan di menu Purchase.

Tanpa filter tanggal, menu ini hanya membaca pengajuan hari ini. Isi tanggal & jam untuk memunculkan lagi pengajuan hari sebelumnya yang belum diinput. Pilih tahap pengajuan, asal barang, atau tanggal untuk menampilkan semua pengajuannya sekaligus; kosongkan semua filter untuk mencari produk manual.

Upload Purchase

Tarik & lepas banyak file Excel atau PDF hasil export menu Purchase. Pilih tanggal tiap file, sistem mengelompokkan per admin, asal barang, dan tahap pengajuan (grup baru dibuat bila belum ada), lalu klik Submit. Data muncul di menu Purchase dan Pengajuan.

Tarik file ke siniatauPDF, XLSX, XLS. Boleh banyak file sekaligus.

Riwayat Download

Setiap kali ada yang menekan Export Excel / PDF di menu Pengajuan atau Purchase, file tersebut tercatat di sini beserta isi datanya. Download hari ini tampil di atas; hari sebelumnya otomatis masuk Riwayat per tahun & bulan & tanggal (tertutup, klik untuk membuka). Tombol Export di bawah menggabungkan semua file yang lolos filter, urut dari yang terlama sampai terbaru. Setiap file diawali header Nama Admin & Asal Barang.

Dashboard Khusus Pemilik

Riwayat Perubahan & Penghapusan

Setiap data Pengajuan, Purchase, Download, Retur, Upload Stok, dan Barang Gudang yang diedit atau dihapus tercatat di sini. Data lama bisa Dipulihkan ke kondisi sebelum diedit / dihapus, atau riwayatnya dihapus permanen. Keduanya wajib memakai kode 6 digit.

Input Form Retur

Isi data pengembalian lalu tekan Submit. Data langsung masuk ke menu Laporan Retur dan tetap bisa diedit di sana. Isian bertanda * wajib diisi.

Input Massal Retur (Excel / CSV)

Upload file Excel Anda apa adanya. Judul kolom yang dikenali: Resi Pengembalian, ID Pesanan, No Tiket Pelaporan, Deskripsi, Due Date, Status, Nama Toko, Keterangan, dan Marketplace (opsional). Kolom lain (mis. SEND) diabaikan, dan baris judul boleh tidak di baris pertama.

  • Resi dan ID Pesanan wajib; baris yang kosong salah satunya ditolak.
  • Due Date: tanggal Excel, teks seperti "Monday, 09 November 2026", atau 20-11-2026 / 2026-11-20. Kosong atau "Cek Berkala" = Cek Berkala.
  • Status: kotak centang dicentang = Done, tidak dicentang = On Progress. Teks On Progress / Failed / Done / Review juga bisa.
  • Kolom tanpa judul yang berisi nama toko otomatis dibaca sebagai Nama Toko.
  • Baris yang resi + ID pesanannya sudah ada dilewati; sebelum disimpan akan ada konfirmasi jumlah data.

Laporan Retur

Semua data dari form Retur. Hari ini tampil di atas; hari sebelumnya masuk Riwayat per tahun & bulan & tanggal. Klik salah satu baris untuk melihat detail lengkapnya (pilih Edit atau Keluar), atau langsung klik tombol Edit di baris; mengubah tanggal / jam input wajib memakai kode 6 digit.

Form Barang Retur

Barang retur / cancel yang kembali ke gudang. Kondisi Baik / Kurang: masuk ke Barang Retur, Barang Gudang, dan Database Produk. Kondisi Rusak / Lecet: hanya masuk ke Barang Retur.

Barang Retur Bermasalah

Semua barang retur yang sudah diinput, bisa difilter per tanggal, kondisi, admin, atau dicari. Pilih kondisi Rusak / Lecet untuk melihat barang bermasalah (tidak masuk Barang Gudang). Edit atau Hapus akan ditolak jika membuat stok gudang minus karena sebagian sudah dikeluarkan. Data lama tanpa kondisi dianggap layak pakai (Baik).

Manifest Ekspedisi & Data BigSeller

Pilih tanggal, tempel manifest, lalu upload Excel BigSeller (boleh banyak file). Warna: kuning = belum discan, putih = discan tapi tidak ada di manifest (klik × untuk menyembunyikan), hijau = cocok dan masuk ke grup hasil scan.

Tarik file Excel ke siniatauTanggal dibaca dari kolom AL. Filter SPX / J&T mengikuti pilihan Ekspedisi manifest. Boleh banyak file.

Scan COD Gagal

Hasil Scan COD Gagal

Dikelompokkan per tanggal dan karung. Hijau = cocok dengan manifest, putih = tidak ada di manifest. Check Status dan Deskripsi bisa diedit langsung.

Scan Barcode / QR

Ketuk ikon kamera lalu arahkan ke Barcode / QR. Bunyi pip = berhasil tersimpan, bunyi tetot = gagal / duplikat. Hasil masuk ke menu Data Scanner. Daftar di bawah hanya menampilkan hasil scan milik akun Anda sendiri.

Hasil Scan Saya Hari Ini

Upload Data Scanner

Tarik & lepas (drag and drop) file PDF atau Excel hasil scan. Boleh banyak file sekaligus, semua sheet Excel ikut dibaca. Urutan kolom: A = No., B = No. Resi, C = Waktu Scan, D = PIC, E = Ekspedisi. Format Excel lama (per ekspedisi atau 3 kolom) tetap bisa diupload.

  • Jam scan dibaca sebagai waktu WIB. Format yang dikenali: sel tanggal Excel, 2026-11-20 14:05:33, atau 20/11/2026 14:05. Penulisan PIC dirapikan otomatis (mis. YANA - RANI menjadi YANA-RANI).
  • Setelah file dibaca, tampil laporan status dulu: Baru, Double (resi + jam scan yang sama, sudah ada di database atau dobel antar file / sheet), Resi sama, jam beda, dan Ditolak. Data baru baru disimpan setelah klik Simpan.
  • Karena double dilewati otomatis, file yang sama aman di-upload dua kali.
Tarik file ke siniatauPDF, XLSX, XLS, CSV. Boleh pilih banyak file sekaligus.

Data Scanner

Semua data scan dari Excel. Hari ini tampil di atas; hari sebelumnya masuk Riwayat per tahun & bulan & tanggal (klik panah untuk membuka / menyembunyikan).

Barang Gudang

Daftar barang retur / cancel yang tersimpan di gudang. Cari dulu di sini sebelum mengajukan barang, supaya barang retur terpakai dan tidak menumpuk.

Input Produk Satuan

Isi No. SKU, Nama Produk, dan Varian (warna). Varian boleh dikosongkan jika produk tidak punya varian. Setelah disimpan, produk masuk ke Database Produk beserta Barcode dan QR dari No. SKU.

Input Produk Massal (Excel / CSV)

Kolom: SKU, Produk, Varian. Satu baris per SKU. SKU yang sudah ada dilewati. Barcode dan QR dibuat otomatis dari SKU.

Database Produk

Edit atau hapus produk memakai kode verifikasi.

List Produk Inputan

Produk baru yang diketik dari Form Pengajuan dan belum ada di Database Produk. Hanya Owner yang dapat menghapus.
